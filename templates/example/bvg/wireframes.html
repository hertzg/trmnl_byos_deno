BVG journey board — wireframes

All frames render at the panel's native 1872 × 1404, scaled to 50 % for preview. Layout is a unified rows list, each row tagged with a person icon, sorted by leave-by. Pictogram convention: 8 = 8-min walk, boxed code = transit leg, pill-shaped = bus, arrows separate legs.

Person A (Office): two acceptable shapes (S5+U2, U8) producing three candidates within the 60-min window before the 09:30 deadline. Person B (Studio): two S-line candidates before the 10:00 deadline. Rows interleaved by leave-by ascending.
