pictogram glyph comparison

walking-leg treatments shown alongside the full set of BVG transit shapes. each transit mode keeps its product semiotics (S-Bahn / Bus = circle, U-Bahn / Tram = square, Regional = diamond, IC/ICE = circle, inverted) so the pictogram reads as one shape language. all walk options use the official BVG haf_prod_walk figure (where a figure is present) flattened to 1-bit black. options H and I extend BVG's product-shape system to the walk leg itself, treating it as its own "product".
