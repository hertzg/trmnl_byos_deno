## Greppable patent text

The patent PDFs above are the official grant documents and are largely scanned images - a plain
`pdftotext` on `US7952557B2.pdf` yields only 13 KB, i.e. the cover sheet. So `text/` holds the full
text of each patent, extracted from its Google Patents page, so quotes can actually be checked:

```
grep -i "soft rails" text/US7952557B2.txt
```

**10 files, 3.0 MB.** Every quote attributed to a patent in
[../sources.md](../sources.md) was confirmed present in these files on 2026-08-30.

## Provenance notes

  plain client, so the snapshot is the only reachable copy.
- `pdi-1p257-00-*.pdf` is likewise an archive snapshot: Pervasive Displays rebuilt their site and
  every `wp-content/uploads/*.pdf` now 404s.
- `micromachines-*.html` is an archive snapshot because mdpi.com serves a CAPTCHA to automated
  requests. It carries the full text, not just the abstract.
